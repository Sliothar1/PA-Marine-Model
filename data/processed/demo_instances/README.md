# Demo instances (GrokD4M `/marine`)

JSON windows for Felix’s three Cork demos. Generated by:

```bash
python scripts/export_demo_instances.py
```

| File | Window | Story |
| --- | --- | --- |
| `2018_jja_ne_atlantic.json` | 2018-06-01 → 2018-08-31 | HAB season / Connemara; modest MHW vs 2023 |
| `2022_jja_galway_connemara.json` | 2022-06-01 → 2022-08-31 | Galway inner bay vs Connemara |
| `2023_june_flagship.json` | 2023-06-01 → 2023-06-30 | CRW frac_mhw ≈ 0.96; national HAB **below** clim |

`samples/*.sample.json` are small committed excerpts. Full `*.json` dumps are gitignored (regenerate locally).

## Copy into GrokD4M (`hackathon-marine-demo`)

```bash
mkdir -p /path/to/GrokD4M/data/marine/instances
cp 2018_jja_ne_atlantic.json /path/to/GrokD4M/data/marine/instances/
cp 2022_jja_galway_connemara.json /path/to/GrokD4M/data/marine/instances/
cp 2023_june_flagship.json /path/to/GrokD4M/data/marine/instances/
```

Each payload has `"copy_to_grokd4m": "data/marine/instances/<id>.json"` and `"honesty"` keys matching Cork lock (STRONG_OISST ~0.295; heatwave ≠ bloom; Chl/ODYSSEA narrative-only).

## Required local inputs

**Preferred:** `data/processed/joined_features.parquet` (gitignored; full national join).

**This repo already tracks** `data/processed/joined_features_osi_sst.parquet` (same OISST/MHW/HAB columns plus ODYSSEA extras). The exporter uses it when the canonical join is missing. ODYSSEA columns are **not** quoted as Cork skill.

Fallbacks: `connemara_farms_scores.csv`, `june2023_case_study_hab_weekly.csv`.  
CRW shelf fraction: `crw_mhw_ireland_daily_summary.csv` (coverage from 2022-01-01; 2018 CRW block will be `available: false`).

If nothing is present, the exporter still writes stubs with `"status": "needs_local_parquet"` and the rebuild command.
